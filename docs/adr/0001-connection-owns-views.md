# 连接拥有视图；文件视图可提升为文件标签，不做独立窗口

一个连接名下可以有任意数量的视图（终端视图、侧栏中的文件视图、文件标签、目录标签），视图只属于创建它的连接，既不能换绑也不能比连接活得更久：连接断开、重连或关闭时，其名下视图一并关闭或复位。文件视图允许提升为文件标签并放入任意分屏组——这推翻了 `docs/superpowers/specs/2026-10-06-dock-workspace-design.md` 中"连接作为不可拆分整体移动、不出现 SFTP 标签"的约束；该约束原本是为了先交付一个简单版本，生命周期安全已由归属规则保证。

## Considered Options

- **Xftp / SecureFX 式独立文件窗口**（本地 + 远程双栏、脱离终端独立连接）：放弃。会话树已承担站点管理；独立窗口要求另一套连接编排与多窗口交互服务，收益集中在传输能力本身，而传输能力与窗口形态无关。
- **文件标签只能留在所属连接的分屏组**：放弃。归属规则已足以防止悬空视图，额外的位置限制只增加交互意外。
