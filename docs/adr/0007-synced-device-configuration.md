# 按安装实例独立同步设备配置，并保留平台默认层

Status: accepted（2026-11-09，待实现）

串口端口及未来其他设备相关参数需要漫游保存，但同一 OS 的不同机器不一定连接同一设备。采用“通用值 → OS 平台覆盖 → 当前安装实例的设备配置”解析顺序；覆盖只影响显式设置的字段。设备记录独立合并与删除，避免在整会话 JSON 内嵌设备字典后被整节点最后写入胜出覆盖。

复用随机设备标识作为安装实例身份，在需要设备配置时即创建，不以启用同步为前提。不采集硬件指纹；正常同步不复制本机身份，整数据目录复制视为迁移，并提供显式“作为新设备”重建身份。重建身份不自动认领原设备的串口绑定，新机器首次使用须确认绑定。

现有实体的 device_id 表示修改来源，不表示配置归属。新增存储必须区分目标设备与修改来源，并使用追加式迁移及同步实体扩展，不改已发布迁移。通用存储以串口为首个使用者，不为假想业务增加专属模型；具体键、索引及 JSON 格式由实现按归属、合并、删除与兼容约束确定。

“参与同步但只由目标安装实例应用”的设备配置不等于“完全不参与同步”的本机专属项。现有连接元数据也不是本机配置仓库。新版本保留未知字段不能改变已发布旧客户端的行为，兼容策略需验证旧端读取、重写与同步，不以新增 JSON 字段代替证据。
