# 连接管理器 F2 重命名设计规格

> 状态：等代理车道抽完会话树之后再改 `MainWindow` 的树键盘。不要和树抽取同时改同一文件。

## 1. 目标

会话树有焦点、且选中的是会话或文件夹时，按 F2 原地改名。虚拟根「Sessions」不能改。

## 2. 交互

- F2：该项名称变成可编辑文本，全文选中。
- Enter：保存。空白则恢复原名，不写库。
- Esc：取消，恢复原名。
- 失焦：与 Enter 相同。
- 文本框、下拉、终端已经聚焦时，F2 不拦截。只有树本身持有焦点才处理。
- 文件夹和会话都改 `Name`。不改主机、用户名、跳板。
- 保存走现有 `SaveNodeAsync`，失败则名称回到保存前的值，并走现有错误提示。

不另开重命名对话框。右键里若已有重命名，F2 调用同一条命令，不复制一套保存逻辑。

## 3. 测试

树控件的按键不必用头less 窗口硬测。可测的是：命令在空白名时不调用保存；非空名写入节点名称；虚拟根命令不可用。按键接线只在手动验收时看：树聚焦时 F2 进入编辑，终端聚焦时 F2 无效果。
