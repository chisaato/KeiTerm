# 终端日常设计规格

> 状态：同一批的最后一条实现车道。不改 `SchemaMigrations`、`SshDialer`、`ConnectionOrchestrator`、会话编辑器连接页。标签栏样式在 `MainWindow.axaml`，等 F2 车道结束再改主窗口。

## 1. 查找

Ctrl+F 在当前终端标签打开查找栏。已有右键复制 / 粘贴 / 全选 / 清屏，查找是补这一块。

- 输入框、上一个、下一个、关闭。
- Enter 下一个，Shift+Enter 上一个，Esc 关闭并把焦点还回终端。
- 无匹配时查找栏说明「无匹配」，不弹窗。
- 用 RoyalTerminal / `TerminalControl` 已有的搜索 API。没有该 API 时停下来写明缺口，不要自己扫屏缓冲再画一层假高亮。
- 关闭查找栏不清除终端选区以外的状态。

## 2. 字体弹窗

配色编辑或终端外观里，用一个窗口编辑已经存在的 `FontWeight` 和 `LineHeight`。字号仍可以留在设置页。不新建字体模型。

窗口字段：字重（与现有存储字符串一致，至少 Regular / Bold）、行距（现有测试里出现过 1.25、1.3 这一类正数）。取消不写回。确定才更新正在编辑的 profile。

## 3. 标签栏对比

未选中、选中、后台活动三种状态必须能靠明度和字重分开，不只靠一个接近背景的色块。用现有 `Kei.*` 令牌，不写死色值。活动点保留。不改标签的关闭、拖动、右键行为。

## 4. 256 色 / true color

`TERM` 已是 `xterm-256color`。本项只修 `TerminalThemeAdapter`：

- 0–15 仍来自配置的 16 色。
- 16–255 在配置没有单独槽位时，按 xterm 6×6×6 色立方加灰度阶生成，不重复刷成某一种 ANSI 色。
- 控件若已把真彩色（直接 RGB）交给渲染器，适配器不得把它覆盖成 256 色索引。若控件还没解析真彩色，记在实现报告里，不要另写一个 VT 解析器。

## 5. 关键字高亮

规则放 Core：一行文本进，高亮区间出。默认规则：

- 不区分大小写的整词 `error`、`fail`
- IPv4
- `http://` 或 `https://` 开头、到空白为止的 URL

区间不重叠时都保留；重叠时更长的优先。纯函数单测覆盖这三条和「erroring 不是 error」。

渲染：只有 `TerminalControl` 已有高亮钩子才接线。没有钩子则 Core 规则照做，钩子记为缺口，禁止往 PTY 回写 ANSI 码来假装高亮。

## 6. 测试

- 查找：若 API 存在，用头less 或控件测试断言下一处匹配移动选区；API 不存在则该测试不写，报告里说明。
- 字体弹窗：确定写回字重和行距，取消不写回。
- 256 色：索引 16 与索引 0 的颜色不同；索引 255 是灰度而不是 ANSI 白的简单复制，除非公式结果碰巧相同。
- 关键字：上表三条规则，外加重叠时取更长区间。
