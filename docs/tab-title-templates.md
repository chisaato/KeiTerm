# 标签标题模板

在 **偏好设置 → 标签栏 → 标签标题模板** 输入规则，例如：

```text
{remote_hostname} | {remote_path}
{local_name} | {remote_ip} | {remote_dirname}
{local_user}@{local_host}:{local_port}
```

终端和文件标签共用模板，图标区分内容类型。保存后立即更新已打开的标签；留空恢复默认命名。终端右键手动重命名优先于模板，重新切换“跟随远端标题”后恢复自动命名。

| 变量 | 来源 |
| --- | --- |
| `{local_name}` | 本地会话名称，含当前标签的手动名称 |
| `{local_host}` | 本地配置的目标地址（可为域名、IP 或别名） |
| `{local_port}` | 本地配置解析后的目标端口 |
| `{local_user}` | 本地配置解析后的登录用户名 |
| `{remote_hostname}` | Shell 目录上报中的主机名，不以本地配置地址冒充 |
| `{remote_path}` | 终端最近上报的有效目录；文件标签使用自身浏览目录 |
| `{remote_dirname}` | 上述目录的最后一段，根目录显示 `/` |
| `{remote_title}` | 远端通过 OSC 0/2 上报的标题 |
| `{remote_ip}` | 目标地址本身为 IP 时，连接成功后提供该目标 IP |

目前不会通过额外远端命令或 DNS 猜测目标 IP；域名目标无法确认实际 IP 时显示 `—`。跳板的回环转发地址、代理服务器地址不会作为目标 IP。终端目录和主机名需要 Shell 集成（OSC 7 或受支持的 tmux/screen 目录标题），目录跟随关闭时仍可接收这些上报。

缺少的远端值显示 `—`。不识别的变量或不匹配的花括号会显示错误并阻止保存。模板最多 512 字符；`{{` 和 `}}` 分别输出字面花括号。替换后的远端文本不会再次被当作模板解析。
