架构设计：协议与分层抽象 (Section 1)

现代化平铺分栏设计（Wave / Warp 风格）与底层分层抽象

分层架构与模块关系：
┌────────────────────────────────────────────────────────┐
│  Kei.Term.App (UI & 交互层)                             │
│  - RemoteFileManagerView (独立通用文件管理器控件)       │
│  - TerminalTabView (平铺 Splitter 伴随侧栏 + 独立 Tab) │
│  - SessionEditWindow (持久化传输协议与模式配置)       │
└──────────────────────────┬─────────────────────────────┘
                           │ 依赖注入
┌──────────────────────────▼─────────────────────────────┐
│  Kei.Term.Core (业务抽象与纯数据模型)                   │
│  - IRemoteFileSystem (目录浏览、文件元数据、CRUD 流操作) │
│  - FileTransferTask / ITransferManager (后台传输队列)    │
│  - FileTransferSettings (Auto / Subsystem / Dedicated) │
└──────────────────────────┬─────────────────────────────┘
                           │ 接口实现
┌──────────────────────────▼─────────────────────────────┐
│  Kei.Term.Ssh (SSH / SFTP / SCP 具体实现)              │
│  - SftpRemoteFileSystem (基于 SSH.NET SftpClient)      │
│  - ScpRemoteFileSystem (基于 SSH.NET ScpClient)       │
│  - SshConnectionMultiplexer (Subsystem 通道复用与降级) │
└────────────────────────────────────────────────────────┘
