# 05 安全网与口令管理

Status: ready-for-agent
Blocked by: 04

见 `../spec.md`「同步协调器」「触发与界面」。

**要做什么：** 让同步出错时可以恢复、批量删除时可以拦住、口令可以更换。用户能在同步页完成首次加入的选择、恢复，以及更换口令和停用同步。

- [ ] 批量删除阈值：一次合并会删除超过 30% 或超过 50 个本机同步实体时，自动同步中止并标记「需要确认」；手动同步时弹出确认，走统一交互服务。
- [ ] 首次加入（本机从未同步过、远端有同步包）：三选一（合并 / 以同步位置为准 / 以本机为准），默认合并；远端为空时直接初始化。
- [ ] 合并前快照：每次合并写回之前保存一份，用 Vault Key 加密，只保留最近 10 份；在同步页可选择其中一份恢复，恢复后的数据在下次同步时胜出。
- [ ] 历史同步包：每次上传前把当前同步包复制到 `history/`，只保留最近 5 份；在同步页可选择其中一份恢复。
- [ ] 更换同步口令：先用旧口令完成一轮同步，再用新口令上传，同时清空历史同步包。其他设备解密失败时提示输入新口令，输入后继续同步。
- [ ] 停用同步：可选删除同步位置中的同步包与历史；本机数据不受影响，同步口令从保险库删除。
- [ ] 所有弹窗都走统一交互服务，不在 ViewModel 上加 `Func<>` 弹窗属性；界面交给 @designer。
- [ ] 同步协调器测试覆盖：阈值中止、三种首次加入、两种恢复、更换口令后旧口令失效且历史已清空、停用。
