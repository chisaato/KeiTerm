# 06 WebDAV 同步位置

Status: ready-for-agent
Blocked by: 03

见 `../spec.md`「同步位置」。

**要做什么：** 用户可以把同步位置设为 WebDAV（Nextcloud、群晖、坚果云等），在同步页填写地址、用户名、密码，测试连接后即可同步。

- [ ] 基于 `WebDav.Client` 实现同步位置：读写主同步包、历史同步包的列出、读取、写入与删除、测试连接；目标目录不存在时自动创建。
- [ ] 默认按 ETag 条件写（`If-Match` / `If-None-Match`），返回 412 时由同步协调器重新执行整轮；配置项可关闭条件写，关闭后改走读回检查。ETag 原样回传，不自行加减引号，以兼容坚果云。
- [ ] 密码存进保险库，同步位置配置属于本机专属项。
- [ ] 同步页增加 WebDAV 的配置表单与「测试连接」，界面交给 @designer。
- [ ] 同步位置契约测试在 `KEITERM_SYNC_BACKEND_TESTS=1` 时连接本机的 WebDAV 服务运行并通过；测试文件头部注释写明如何起服务。
