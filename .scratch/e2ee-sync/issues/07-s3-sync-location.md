# 07 S3 兼容存储同步位置

Status: ready-for-agent
Blocked by: 03

见 `../spec.md`「同步位置」。

**要做什么：** 用户可以把同步位置设为 S3 兼容存储（AWS S3、Cloudflare R2、MinIO、阿里云 OSS、腾讯云 COS），在同步页填写端点、区域、桶、前缀与访问密钥，测试连接后即可同步。

- [ ] 基于 `AWSSDK.S3` 实现同步位置：支持自定义端点与 path-style 访问；读写主同步包、历史同步包的列出、读取、写入与删除、测试连接。
- [ ] 条件写使用 `IfMatch` / `IfNoneMatch`，返回 412 或 409 时由同步协调器重新执行整轮。配置项可切换条件写；阿里云 OSS、腾讯云 COS 默认关闭，关闭后走读回检查。
- [ ] 访问密钥存进保险库，同步位置配置属于本机专属项。
- [ ] 同步页增加 S3 的配置表单与「测试连接」，界面交给 @designer；与 06 的表单共用同一套同步位置选择框架。
- [ ] 同步位置契约测试在 `KEITERM_SYNC_BACKEND_TESTS=1` 时连接本机的 MinIO 运行并通过；测试文件头部注释写明如何起服务。
