# 08 自动触发与状态

Status: ready-for-agent
Blocked by: 03

见 `../spec.md`「触发与界面」。

**要做什么：** 用户启用同步后不需要再手动点击：启动时、修改后、定时都会自动同步，同步在后台进行、不阻塞界面，状态始终可见。

- [ ] 应用启动且保险库解锁后同步一次。
- [ ] 任何同步实体发生本地修改后，防抖 30 秒再同步。
- [ ] 运行期间每 5 分钟同步一次。
- [ ] 同一时刻只运行一轮；运行中再次触发时合并为下一轮。
- [ ] 保险库锁定时暂停并显示「保险库已锁定，同步暂停」，解锁后自动补跑一轮。
- [ ] 同步失败时状态显示可读原因（网络、凭据、口令、同步包损坏、需要确认），本机数据不变；下一个触发点照常重试。
- [ ] 同步状态在同步页可见；是否在主窗口加一个轻量状态指示，由 @designer 决定。
- [ ] 测试用可控时钟与测试同步位置覆盖：防抖、定时、单轮串行与合并触发、锁定暂停与解锁补跑。
