# 04 快照扩展到全部应用数据

Status: ready-for-agent
Blocked by: 03

见 `../spec.md`「同步实体与本地记账」「同步协调器」。

**要做什么：** 让同步包覆盖全部应用数据，只排除本机专属项。在一台设备上改任何设置、身份或 Profile，同步后都能在另一台设备上看到。

- [ ] 身份连同秘密：导出时用本机 Vault Key 解密，导入时用目标设备的 Vault Key 重新加密，明文只在内存中流转。
- [ ] 代理连同密码、端口转发、外部编辑器（含按操作系统区分的路径）、文件关联。
- [ ] known_hosts 按自然键（主机、端口、公钥）合并，两台设备各自信任过的同一个主机密钥合并后只有一条。
- [ ] 连接元数据按（会话、键）合并。
- [ ] `settings.json` 按设置项合并：不同设置项的修改都保留，同一项以最后写入为准。
- [ ] `profiles.json` 中每个 Profile 作为一个同步实体合并。
- [ ] 本机专属项排除清单：窗口位置与尺寸、最近打开的目录、快速解锁登记、同步配置本身（含同步位置凭据）、设备标识。有测试保证它们不进入同步包。
- [ ] 悬空引用（跳板、代理、身份、Profile、终端 Profile）：合并时不改写，读取时把对应会话标记为「配置不完整」，界面上有提示（提示样式交给 @designer）。
- [ ] 同步协调器的双设备测试覆盖以上每类同步实体的往返与冲突裁决。
