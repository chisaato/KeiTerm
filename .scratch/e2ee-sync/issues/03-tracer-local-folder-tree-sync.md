# 03 贯通：本地目录 + 会话树手动同步

Status: ready-for-agent
Blocked by: 01, 02

见 `../spec.md`「同步协调器」「同步位置」「触发与界面」。

**要做什么：** 端到端打通最窄的一条路径：两台设备用同一个本地目录和同一个同步口令，手动同步会话树（含会话配置）。另一台设备能看到增、删、改、移动，并且符合合并规则。

- [ ] Core 中定义同步位置抽象与同步协调器；Infrastructure 中实现本地目录同步位置（先写临时文件再原子改名，不支持条件写）。
- [ ] 快照格式带版本号，包含写入方设备标识与写入时间；读到更高版本时拒绝合并并提示升级。
- [ ] 合并规则：按修改时间取较新者，时间相同时比较设备标识；墓碑参与比较；修改晚于删除的实体保留，父节点已删除时移到根目录。
- [ ] 合并结果在单个事务里写回本机，写回后刷新会话树。
- [ ] 不支持条件写时，上传后读回并比较哈希，不一致就重新执行整轮，最多 3 次；用测试同步位置注入「上传后被覆盖」，验证双方修改都保留。
- [ ] 同步后清理超过 180 天的墓碑。
- [ ] 设备标识首次同步时生成，属于本机专属项；同步口令存进保险库，保险库锁定时同步返回「保险库已锁定」。
- [ ] 同步位置契约测试骨架，先只跑本地目录。
- [ ] 设置窗口新增最简的「同步」页：选择本地目录、设定或加入同步口令、立即同步、上次同步状态（时间、结果、最后写入设备、错误原因）。界面交给 @designer。
- [ ] 同步协调器的双设备测试覆盖上述行为，并包括「口令错误时本机不变」。
