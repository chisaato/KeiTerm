# 04: .NET Serial 端到端连接

**What to build:** 用户可选择本机串口、保存参数与设备绑定，打开控制台、使用自动流控及引脚操作，并在关闭或拔插时得到准确状态。

**Blocked by:** 01 — 协议路由预重构；02 — 通用设备配置与独立同步。

**Status:** ready-for-human

- [x] 编辑与保存端口绑定、波特率、数据位、校验位和停止位，按三级配置优先级解析；新安装实例首次确认绑定。
- [x] 支持无流控、自动 RTS/CTS 与 XON/XOFF；提供手动 DTR/RTS 与 Break，自动流控占用引脚时明确处理冲突。
- [x] 不伪造网络主机、端口、SSH 认证、文件系统或窗口协商能力。
- [x] 区分无权限、设备不存在、被占用、断开与取消；读写/关闭不能无限拖住工作区，资源归属与断开通知正确。
- [x] 虚拟 PTY 端到端验证收发、取消、关闭、重新打开；配置与界面测试验证绑定及参数切换。
- [ ] 真机验证流控、引脚、Break 和 USB 拔插，保留命令/操作、环境与结果；硬件缺失如实列为待验，不把虚拟测试视为通过。
- [x] 显式选择尚未实现的 Go Serial 时明确报错。

## 验收与阻塞

软件实现、真实 PTY 与普通用户真实权限拒绝/恢复重开均在最终完整测试中通过。Go 已由工单 07 接入，未配置 provider 时明确拒绝，不回退。流控与引脚的勾选表示实现/配置契约完成，不表示电气效果已验；仅剩未勾的真机条款需要测试适配器、对端和接线。步骤及平台边界见 `docs/design/multi-protocol-validation.md`，不在任意 ttyS 节点或生产设备试验。
