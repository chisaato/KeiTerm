# 03: .NET Telnet 端到端连接

**What to build:** 用户可编辑、保存并打开 Telnet 会话，在工作区交互并准确看到关闭或失败；无文件能力时不出现 SSH 文件操作。

**Blocked by:** 01 — 保持 SSH 行为的协议路由预重构。

**Status:** resolved

- [x] 贯通配置、协议默认端口、编辑交互、持久化与连接；标明未加密安全属性。
- [x] 实现流式 IAC 转义、跨块解析、子协商及 NVT；支持 BINARY、ECHO、SGA、TTYPE、NAWS 的合理客户端策略。
- [x] 按方向维护协商状态，避免循环；未知选项正确拒绝，NAWS 未接受时不发送无效窗口子协商。
- [x] 无 SSH 凭据与主机密钥提示，不初始化文件系统，隐藏文件入口；拖放不意外走 SFTP/SCP。
- [x] 主动关闭、取消、对端关闭、异常与重连状态准确，旧连接输出不污染新连接。
- [x] 本地真实 TCP 对端覆盖转义 255、分片、协商拒绝与窗口变化；ViewModel/控件测试覆盖编辑保存与能力显示。
- [x] 显式选择尚未实现的 Go Telnet 时明确报错，不静默回退。

## 验收

真实 TCP 协议行为、编辑保存、显式 Telnet:22 保留、文件能力与在途取消回归均在最终完整测试中通过。Go 已由工单 06 实现；缺少 provider 或不支持组合的拒绝路径仍有测试，不以回退掩盖。证据见 `docs/design/multi-protocol-validation.md`。
