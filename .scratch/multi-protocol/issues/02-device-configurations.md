# 02: 通用设备配置与独立同步

**What to build:** 用户无需启用同步即可使用安装实例配置；参数按通用值、OS、当前实例逐字段覆盖，各设备配置可独立漫游且互不覆盖，并可显式重建设备身份。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 以追加迁移实现可复用配置存储，区分配置归属对象、类别、目标安装实例与修改来源；串口之外无需新增假想业务。
- [x] 身份在使用配置前创建；正常同步不复制身份，不采集硬件指纹。
- [x] 通用值 → OS 覆盖 → 当前设备覆盖逐字段解析；删掉覆盖恢复下层值。
- [x] 不同设备记录独立同步合并；验证离线并发、同记录确定性裁决、墓碑和归属对象删除。
- [x] 提供显式“作为新设备”操作及必要交互，原设备记录不被自动认领；不得借该操作绕过保管库安全。
- [x] 从公开配置/同步入口验证重启与多实例结果，提供一条可运行的配置解析演示或集成用例，非仅数据库单表测试。
- [x] 明确旧客户端未知实体/字段行为并实施保护策略；不以新端扩展字典宣称旧端天然安全。
- [x] 设备配置不接收明文秘密，完全不参与同步的本机专属项仍保持独立语义。

## 验收

真实 SQLite 配置/同步入口、覆盖删除、墓碑、重启、身份重建与外键行为测试通过；只追加 schema v12。实际旧 Core 拒绝同步 v2，但本地重写会丢整个 Serial，必须升级，不能用旧端编辑新配置或承诺同目录降级安全。前后数据、版本门及最终完整测试证据见 `docs/design/multi-protocol-validation.md`。
