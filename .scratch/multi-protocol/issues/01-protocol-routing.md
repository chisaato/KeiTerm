# 01: 保持 SSH 行为的协议路由预重构

**What to build:** 将连接类型分发与 SSH 专有拨号流程分开，让既有 SSH 会话经新入口保持原行为，为非 SSH 类型提供明确能力错误而非误拨 SSH。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 配置解析保留连接类型，网络默认端口按类型解释，Serial 不借用网络端口。
- [x] SSH 认证、信任确认、多跳、终端与文件服务继续经过既有安全边界。
- [x] 通用入口不强制所有类型提供文件系统或动态尺寸；能力模型容纳运行时协商，不以假文件系统冒充支持。
- [x] 未支持的类型/引擎明确报错，无静默回退；非 SSH 不进入 SSH 凭据收集。
- [x] 从连接入口验证 SSH 行为和拒绝路径；增补配置类型保留测试，并运行聚焦的 SSH 回归。

## Context

这是经批准的预重构例外，不先构建庞大协议框架；新类型的真实垂直接入由后续工单完成。

## 验收

配置/路由、连接世代与能力入口回归，以及真实 SSH.NET/Go SSH 终端和文件链路均在最终完整测试中通过。证据及命令见 `docs/design/multi-protocol-validation.md` 第三轮记录。
