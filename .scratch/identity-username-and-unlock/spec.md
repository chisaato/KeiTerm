# 身份编辑：打开即解锁、登录用户名归属身份

Status: resolved

## 范围与办结口径

本 spec 补录身份编辑体验的两处改进。代码已随提交 `7e641a6` 合入（该提交标题为上传框与中文输入，身份相关改动一并带入）。

## 结论

- 身份编辑几乎必然读写保管库材料，解锁时机应前移到打开编辑器时，而不是在导入私钥或「应用」的瞬间打断用户。
- **身份 = 用谁登录 + 怎么认证**。密码天然属于某个用户名，身份持有登录用户名；会话上的用户名降为可选覆盖。
- 解析链：会话显式用户名 → 身份用户名 → 全局默认用户名 → 当前系统用户。
