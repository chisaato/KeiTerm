# 全局设置窗口重构：分组导航、设置行卡片与下钻编辑

Status: ready-for-agent

## 背景

现状（2026-10-18，`main@d8c608c` + 未提交的传输校验/归档 WIP）：

- `Views/SettingsWindow.axaml` 约 1325 行，所有页面写在同一文件里；`SettingsWindow.axaml.cs` 214 行。
- 左侧 `CategoryNavListBox` 平铺 10~11 个分类，每项两行（标题 + 副标题），纵向拥挤；“外观 / 会话树 / 终端外观 / 标签栏”的边界不清。
- 右侧采用「标签 ↔ 控件」两栏网格，说明藏在 `*Tip` 悬浮提示里；排序列表、回退字体、标题模板等复杂编辑器直接内嵌，层层缩进，页面越拉越长（外观 49 个键、文件传输 41 个键）。
- 页面 VM 已按页拆分（`_general`、`_appearance`、`TreeSettingsProxyPage`、`TerminalSettingsCombinedPage`、`TerminalAppearanceSettingsPage`、`TabBarSettingsProxyPage`、`_ssh`、`_security`、`_fileTransfer`、`ProxySettingsPage`），由 `SettingsViewModel.Categories` 组装。

参考风格：JetBrains IDE 设置窗口。

## 设计决策

1. **只有一级导航 + 一层下钻。** 不做多级树（SecureCRT 式 4 级不采用）。将来条目确实多到放不下时再重构。
2. **导航分组**：左侧单行条目（图标 + 标题，无副标题），以不可选的分组标题分隔：
   - **应用**：常规 · 外观 · 会话管理器
   - **终端**：行为 · 配色与字体 · 标签栏
   - **连接**：SSH · 代理 · 安全
   - **文件**：传输 · 文件管理与编辑器

   说明：
   - “会话管理器”即左侧会话树的排序、密度、尺寸设置，与终端解耦，归入“应用”。原“常规”中的会话树排序项一并迁入。
   - 快捷键目前只有命令面板快捷键与标签切换修饰键，暂以卡片留在“常规”；条目增多后再独立成“快捷键”页。
   - 原“文件传输”拆为“传输”（队列、冲突、续传、重试、校验、归档）与“文件管理与编辑器”（文件管理器、缓存与监视、外部编辑器、文件关联）。
   - 副标题文案（`Settings.Categories.*Desc`）移到右侧页头作为页面描述。
3. **页头**：面包屑（`分组 / 页面[ / 子页]`）+ 页面标题 + 一行描述。
4. **统一设置行 `SettingRow`**：左侧标题 + 说明（原 `*Tip` 文案直接作说明行显示，不再依赖悬浮），右侧控件右对齐；行间细分隔。内容区有最大宽度，宽窗口下不被拉散。
5. **卡片分节 `SettingsCard`**：原 `*Section` 标题成为卡片标题，卡片内若干 `SettingRow`。
6. **复杂编辑器分两类处理：**
   - **摘要行 + 下钻**（小编辑器）：主页只显示一行摘要（如 `SHA-256 › SHA-1 › MD5   编辑 ›`），点击后右侧内容区切换为子页面，面包屑可返回：
     - 界面回退字体列表、终端回退字体列表
     - 哈希算法优先级、归档格式优先级（带启用开关的行：开关在行内，排序在下钻页）
     - 标签标题模板的变量参考（模板输入与预览留在主页）
   - **整页编辑器**（本身就是一页）：代理档案、外部编辑器 + 文件关联、（将来的）快捷键表——占据所在页的主体，页面内主从列表，不再下钻。
7. **高级项折叠**：每张卡片可有“显示高级选项”折叠区，例如重试退避与间隔、监视器轮询间隔、写入防抖、终端类型等低频项。
8. 底部 取消 / 应用 / 确定 行为不变。
